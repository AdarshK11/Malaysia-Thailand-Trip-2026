# Malaysia + Thailand Trip 2026

Static trip website for the confirmed Sep 22-Oct 2, 2026 flow:

- Hyderabad to Kuala Lumpur
- Kuala Lumpur to Phuket
- Phuket to Bangkok
- Bangkok to Hyderabad

## Pages

- `index.html` has the overall route, confirmed flights, and confirmed stays.
- `kuala-lumpur.html` has Kuala Lumpur logistics and activity slots.
- `phuket.html` has Phuket logistics and activity slots.
- `bangkok.html` has Bangkok logistics and activity slots.

## Privacy note

Booking references and PNRs are intentionally not published in the static site files.
Keep those in private notes or a password manager.

## Local preview

Open `index.html` in a browser. No build step is required.
